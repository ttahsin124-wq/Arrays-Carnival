## 📖 About

This repository contains my solutions to various **Array** problems on [LeetCode](https://leetcode.com/). Arrays are one of the most fundamental data structures in programming, and mastering them is crucial for coding interviews and competitive programming.

**Goals of this repository:**
- Provide clean, efficient, and well-documented solutions.
- Include multiple approaches (e.g., brute force, optimized, two-pointer, etc.) where applicable.
- Help others understand the thought process behind each solution.
